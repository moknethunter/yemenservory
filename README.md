## ✨ المميزات

- 🎯 دقة عالية باستخدام FusedLocationProvider مع فلتر Kalman
- 📴 يعمل دون إنترنت
- 🔄 معايرة تلقائية بحركة لولبية
- 📊 تصدير Excel (CSV)
- 🌍 دعم WGS-84
- 🎨 واجهة عربية RTL

## 🚀 التثبيت

### تحميل APK
حمّل أحدث إصدار من [Releases](../../releases)

### البناء من المصدر
```bash
git clone https://github.com/YOUR_USERNAME/YemenSurveyor.git
cd YemenSurveyor
./gradlew assembleDebug
```

## 📖 الاستخدام

1. افتح التطبيق ووافق على صلاحية الموقع
2. حرّك الهاتف بحركة لولبية (شكل 8) لمدة 5 ثوانٍ
3. ثبّت الهاتف على حامل ثابت
4. انتظر حتى تظهر الإحداثيات
5. اضغط "حفظ النقطة"
6. كرر لكل نقطة
7. اضغط "تصدير Excel"
